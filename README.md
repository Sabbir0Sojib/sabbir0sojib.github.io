# sabbir0sojib.github.io

Personal website of **Md Sabbir Islam**, Remote Sensing and Geospatial Deep Learning.
Live at **https://sabbir0sojib.github.io**

## How to edit your website (no code)

All the words, maps and photos live in simple data files in the `content/` folder:

| File | What it holds |
|---|---|
| `content/site.json` | Page titles and intros, home section titles, contact note, footer text |
| `content/profile.json` | Name, greeting and big headline, bio, photo and photo caption, facts, interests, experience, skills, awards, languages, emails, ORCID, links |
| `content/research.json` | Papers, manuscripts and field work (Research page) |
| `content/projects.json` | Code projects with a GitHub repo (Projects page) |
| `content/maps.json` | Single maps (Maps page). Maps without an image go under "More maps". |
| `content/gallery.json` | Photos (Gallery page) |
| `content/places.json` | Places for the Pin the Place game (Fun page) |

### Option 1 (easiest): Pages CMS, a form-based editor

1. Go to **https://app.pagescms.org** and click **Sign in with GitHub**.
2. The first time, it asks to install the Pages CMS GitHub app. Allow it for the repository `sabbir0sojib.github.io`.
3. Open the repository. On the left you will see **Page titles and text**, **Projects (GitHub)**, **Maps**, **Research**, **Gallery (photos)**, **Profile** and **Fun game landmarks**.
4. Click one, then:
   - **Add** a new item with the add button at the bottom of the list,
   - **Edit** any field,
   - **Delete** an item with its menu,
   - **Drag** items to change their order,
   - **Upload** a map or photo straight from the image field.
5. Click **Save**. The website updates about 1 to 2 minutes later. Reload with Ctrl + Shift + R.

The forms are defined in `.pages.yml`.

### Option 2: directly on GitHub

1. **Upload an image:** open the repository on github.com, go to `assets/img/work` (maps) or `assets/img/photos` (photos), click **Add file > Upload files**, and commit.
2. **Edit text:** open a file in `content/`, click the pencil icon, change the text between the quotes, and click **Commit changes**.
   To add an item, copy one `{ ... }` block, paste it after a comma, and change it. Image paths look like `/assets/img/work/my-map.webp`.

Rule for all text on this site: no em dash or en dash characters.

## For developers

Plain HTML, CSS and JavaScript on GitHub Pages; no build step for the live site.

| File | Role |
|---|---|
| `index.html` (profile), `research.html`, `projects.html`, `maps.html`, `gallery.html`, `fun.html` | Page shells, generated by `.impeccable/build-pages.py` |
| `assets/js/site.js` | Loads `content/*.json`, renders pages, filters, lightbox, copy buttons |
| `assets/js/game.js` | Pin the Place game (Leaflet, bundled Natural Earth outlines, no tile service) |
| `assets/css/site.css` | Styles. Colour variables at the top (`--accent` is the green) |
| `assets/data/region.geojson` | Bangladesh and neighbours, Natural Earth 1:10m via world-atlas |
| `assets/vendor/leaflet/` | Leaflet 1.9.4 (BSD-2) |

After changing CSS or JS, bump `VER` in `.impeccable/build-pages.py`, run it, and commit, so browsers load the new files.
Design records: `PRODUCT.md`, `DESIGN.md`.
